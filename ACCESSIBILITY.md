# Accessibility

This applies to every PHAEMOS repository that does not have its own `ACCESSIBILITY.md`. The platform's own statement, covering the dashboard, the nodes and the documentation, lives in [phaemos/phaemos](https://github.com/phaemos/phaemos/blob/main/ACCESSIBILITY.md) and takes precedence there.

## Documentation

Documentation across the organisation aims to:

- Use a real heading outline, so screen readers and the page outline can jump between sections.
- Use link text that says where the link goes, never "click here".
- Give images, diagrams and badges alt text. Write diagrams as Mermaid where possible, so their content is text.
- Show code, commands and output as text, never as screenshots.
- Never rely on colour alone: callouts carry a label such as Note, Tip or Warning.
- Use plain language, explaining a term where it first appears.

## Reporting a barrier

If anything in a PHAEMOS repository is hard to read or use, open an issue on [phaemos/phaemos](https://github.com/phaemos/phaemos/issues/new/choose) with the `accessibility` label. Accessibility problems are treated as bugs.
