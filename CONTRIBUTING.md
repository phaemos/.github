# Contributing

Thanks for taking an interest in PHAEMOS.

> [!IMPORTANT]
> All development happens in [phaemos/phaemos](https://github.com/phaemos/phaemos). The component repositories (`backend`, `frontend`, `firmware`, `hardware`, `infra`, `client` and `edge`) are read-only copies published from it, so pull requests opened there cannot be merged.

The full guide, with local setup, the checks to run and the commit style, is [CONTRIBUTING.md in the monorepo](https://github.com/phaemos/phaemos/blob/main/CONTRIBUTING.md).

The quickest way to try PHAEMOS without hardware is the telemetry simulator in [client/](https://github.com/phaemos/phaemos/tree/main/client), which can play a healthy machine or one developing a fault.

More about the maintainer: [isaacadjei.me](https://isaacadjei.me).
