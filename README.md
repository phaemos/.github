# phaemos/.github

Organisation-wide files for [PHAEMOS](https://github.com/phaemos/phaemos).

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organisation profile shown on [github.com/phaemos](https://github.com/phaemos) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct for every repository without its own |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide, pointing to the monorepo |
| [`SECURITY.md`](SECURITY.md) | Default security policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`FUNDING.yml`](FUNDING.yml) | Sponsor links |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Sends new issues to the monorepo |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Reminds contributors that component repositories are read-only |

GitHub uses these files for any repository in the organisation that does not have its own copy. The monorepo carries its own, fuller versions.
